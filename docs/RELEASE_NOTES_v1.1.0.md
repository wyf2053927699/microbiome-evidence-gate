# Microbiome Evidence-Gate Framework v1.1.0

This release adds the colorectal cancer paired multi-omics extension and updated framework-behaviour visualisation used in the candidate manuscript revision.

## Added

- Paired metagenome-metabolome analysis of 347 CRC-study participants.
- Deterministic discovery and held-out validation workflow.
- Alternative-profiler, CRC-only, healthy-only, presence/absence and joint-taxon robustness analyses.
- External GSE241076 glycocholic-acid host-response analysis.
- Updated source scripts for the exhaustive binary-state, one-bit-transition and coding-error benchmark figure.
- Source scripts and author-generated derived data for Figure 7, Figure 8 and Supplementary Figure 4.
- Updated gate matrix, figure contract and claim-boundary documentation.

## Claim boundary

The CRC result is classified as a triangulated candidate taxon-associated glycocholate-host response axis. It does not establish microbial glycocholate production, same-participant mediation or causality.
